# 2026-10-02 — Prototype v1 → v3 (30 levels)

> **Imported** from claude.ai chat "Blast Ranger physics game with fun levels" (https://claude.ai/chat/ed427073-5fef-4f8a-86f8-9b4958764a58). Work happened in that chat before this repo existed; timestamps are the chat's real message times (local +03:00). Code lives in the claude.ai artifact, **not in this repo**.

## What happened

- **v1 (13:40–13:54 UTC)** — From 11 reference screenshots of a mobile bazooka ad, built *Blast Ranger*: single-file HTML5 browser game on **Matter.js**. Drag-back slingshot aim with dotted arc. Grenades (gravity arc, bounce, fuse) and rockets (near-straight, impact). Distance-falloff blast impulse, mass-aware; stone occludes blasts; wood/ice fracture; ragdoll enemies; fall/crush/topple deaths; chain-reacting red barrels. 12 levels, 3-star scoring by shots used, progress in localStorage, SFX, slow-mo final kill. Auto-ran physics on every level (stable until shot, clearable).
- **v2 (→14:17)** — Player health (100) + self-damage from own blasts (occluded by walls), crush/fall damage. Shooter enemies with line-of-sight bullets. Physics-directed blood spray + ground stains, gibbing on close blasts, sparks/embers/scorch, splinters. "Blood: on/off" toggle. **Green portals** (from L5): preserve velocity, aim preview follows through portal. 18 levels. Fixed tunneling (bodies passing through walls/ground). Progress reset due to reorder.
- Made artifact **public**; friends (incl. iPhone/Safari) play via link. Updates go live at the same URL.
- **v3 (→15:21, fixed 19:15)** — New enemies: archers (arcing arrows that stick), sword+shield knights (run/jump/climb, front shield blocks blasts, drop weapons as bodies), jetpack troopers (throw grenades, landing-circle telegraph). Ropes, balloons, black holes (bend shots; preview curves), bouncy walls. 30 levels ("Final stand"). Background music with ducking on explosions; music toggle.

## Bugs / lessons

- **"Dying for no reason"**: launcher recoil tilted the player and tilt counted as death. Fix: player keeps balance, dies only at 0 HP or off-map; solid ground behind spawn; death screen states cause + tip.
- First fix **didn't actually ship** — the update wasn't saved before publishing, so the link ran the old build. Rebuilt and verified with 150 random-shot auto-plays across 30 levels → 0 causeless deaths. **Lesson: verify the published build, not the local one.**
- User asked for *light* gameplay music; first take was too slow/ambient. Replaced with upbeat bass/beat/arpeggio/marimba, quiet, melody rests, ducks on blasts.
- Artifact publish approval card didn't appear for the user once; re-publish worked.
